Projeto renomeado de "Brokers Bio" para "Brokers App".
Posicionamento: plataforma para criar seu próprio app de imóveis.
Público-alvo: corretores, imobiliárias e construtoras.
Destaques na landing page: PWA instalável, link na bio do Instagram, CRM integrado.
Todas as referências "Bio" foram trocadas por "App" em todo o codebase.
